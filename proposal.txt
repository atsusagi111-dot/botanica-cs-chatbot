# フルスタック CS チャットボット 提案書

## 1. 現状の課題
- 月 500 件の問い合わせ、返信に 1〜2 日 → 顧客離脱
- オペレーター 2 名では捌ききれない物量
- カテゴリ別の困りごと傾向が見えない

## 2. 提案する解決策
**MVP（2 週間）**:
- 顧客側: ブランドサイトに埋め込めるチャットウィジェット
- AI 自動応答（FAQ ベース、500 件のうち 70% を自動対応想定）
- オペレーター側: チャット一覧 + リアルタイム返信画面
- AI が答えられない質問は自動でオペレーターにエスカレーション
- 営業時間外は AI のみ対応 + 翌日対応キュー

**Phase 2 ロードマップ**:
- 感情分析・分析ダッシュボード（週次レポート）
- Shopify 在庫・配送 API 連携（自動回答精度向上）
- ブランドカラー精緻化・テンプレート回答

## 3. 期待される効果
- 自動応答 70% カバー → 返信時間 1〜2 日 → **数秒**
- オペレーター負荷 50% 削減
- 営業時間外も即レス → **顧客離脱を半減**

## 4. 技術構成
- 顧客側: React チャットウィジェット
- 管理画面: Next.js + Vercel
- DB / Realtime / Auth: Supabase
- AI: Claude API（Sonnet 4.6）

## 5. 費用・スケジュール
- 開発期間: 2 週間
- 初期費用: **98 万円（税込）**
- 月額: **約 8〜10 万円**（Supabase Pro + Claude API + Vercel Pro）
